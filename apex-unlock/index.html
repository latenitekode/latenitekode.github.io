How it works

05 / RULES

Each standard Legend costs 12,000 tokens. Level-up rewards are 600 tokens starting at account level 4. The calculator subtracts your current XP from the first level-up, then adds the XP needed for subsequent levels.

Early levels scale to 18,000 XP at level 57. Prestige bands use 18k / 20k / 23k / 28k / 36k XP, with 18k token cycles after the final cap (community documented). Exact prestige thresholds are estimates; check your in-game XP denominator. The Welcome Pass may separately award 12,000 tokens; add those only once received. Events, purchases, XP changes and token spending are not predicted.
