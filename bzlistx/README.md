# BZListX - বাজারের হিসাব

Free, lightweight Bengali shopping list for WhatsApp-friendly monthly expenses.

- Blank on first visit; anyone can add their own name, month, shopping entries and prices.
- Automatically totals the prices (supports Bangla/English digits).
- One-click copy keeps the **•** bullets and full total for WhatsApp sharing.
- Local autosave per browser/device; no backend, no account, no shared data.
- JSON export and import for manually transferring or backing up lists.

> Note: Entries are not synced between devices. Opening the same URL does not show another user's shopping data. Use JSON import/export for transfer.

Open `index.html` locally or publish it to GitHub Pages.
