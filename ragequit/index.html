I didn't fix my aim.
I automated the aftermath.

There comes a time in every Apex player's life when the squad is gone, the banner is expired, and your motivation is somewhere underneath the dropship. You could navigate the menus like a normal person. Or you could spend an absurd amount of time making a mouse do it for you.

Obviously, I chose the second option.

The weapon of choice? A Logitech G102 LIGHTSYNC whose primary left-click had already given up on life. A cheaper mouse could remember its macros without software. This one needed G HUB, Lua, several experiments, and the kind of patience usually reserved for debugging production databases.

“Sometimes the best movement tech is moving back to the lobby.”

The bug that humbled me

First, the script listened for the wrong mouse-button number. Then it tried the key name esc instead of the G HUB Lua key name escape. Then the cursor finally reached YES... and the click wouldn't register. The fix? A slightly longer press.

My mouse was broken, my patience was broken, and somehow the code came out working.

ragequit.lua — the sacred settingsLUA
-- G HUB Lua: 2 is RIGHT-CLICK
local TRIGGER_BUTTON = 2
local YES_X = 29800
local YES_Y = 44750
local MOUSE_HOLD_MS = 150
local ENABLE_FINAL_CLICK = true

-- escape, not esc. Yes, it matters.
TapKey("escape")

Should you actually use this?

If you've ever needed an oddly specific Lua macro, the fully documented source is yours to inspect and modify. Just remember: the original trigger was literally the right mouse button. While active, every right-click starts the sequence, including when you're trying to aim. That's a spectacularly bad surprise in a live match. Change the trigger or disable the script when you're playing.

Also, game policies and anti-cheat behavior can change. This is a personal experiment, not a promise that any automated input is permitted or will keep working.

⚠ The big red flag

The script is configured for literal right-click. That means it will trigger on normal aiming if the G HUB profile stays active.

Keep it disabled during ordinary gameplay, or rebind it to a dedicated button and test carefully.
